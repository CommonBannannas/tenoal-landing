# Tenoal — Estrategia e IA

Sitio web en español de Tenoal, consultoría de soluciones de inteligencia artificial y software en Ciudad de México.

Esta es una copia estática de la página de Tenoal. Incluye la imagen de Ciudad de México generada con IA, servicios, experiencia del equipo y datos de contacto.

## Publicación

La copia está lista en la rama `main`. Para activar GitHub Pages:

1. Abre [Settings → Pages](https://github.com/CommonBannannas/tenoal-landing/settings/pages).
2. En **Build and deployment**, elige **Deploy from a branch**.
3. Selecciona **main** y **/ (root)**, y pulsa **Save**.
4. Espera a que GitHub termine la publicación.

La dirección prevista es <https://commonbannannas.github.io/tenoal-landing/>. Estará disponible cuando la publicación termine.

Una vez activado Pages, los cambios enviados a `main` se publican allí. Los cambios en la página original deben copiarse también a este repositorio.

## Archivos

- `index.html`: contenido de la página.
- `styles.css`: estilos adaptables a distintos tamaños de pantalla.
- `app.js`: menú, ejemplos de aplicación y formulario.
- `assets/`: imagen generada con IA e icono.
- `.nojekyll`: permite servir los archivos directamente.

## Contacto

El formulario abre un borrador en la aplicación de correo del visitante dirigido a `contacto@tenoal.com`. El visitante debe enviar el correo. La página no dispone de un servidor de envío ni almacena solicitudes. El buzón debe existir con su proveedor de correo.
